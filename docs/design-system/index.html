LeadershipServiceInnovation
Tabs. A sliding indicator follows the active tab. Arrow keys switch tabs, and the row scrolls sideways on narrow phones. Used for membership on the About page.
Panels fade up when selected. Tab buttons are at least 44px tall for thumbs.
Real app: Radix Tabs component, styled with these classes.
Content slides open smoothly. One item stays open at a time in “single” mode.
Used for governance and leadership roles, so long pages stay short on phones.

Motion rules: content must exist in the server HTML (never hide it until JavaScript runs) · animate only opacity and transform · keep each effect under about 1 second · turn it all off for “prefers-reduced-motion” · tilt and magnetic effects only for mouse pointers, never touch.

Icons

Icons: Lucide only

The app uses lucide-react. Never use emoji or system icons, because they look different on every device. Icons tagged homepage or ui kit are already in the code. Click one to copy its import.

Usage: import { GraduationCap } from "lucide-react" then <GraduationCap className="size-6" />. Size with size-5 inline or size-6 in a tile. Icons support text, they never replace it.
